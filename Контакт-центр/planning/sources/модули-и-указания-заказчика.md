# Выжимка: «Описание программных модулей.docx» и «Промпт.docx»

## 1. Описание программных модулей (таблица, 4 строки)

| Модуль-образец | Назначение (по документу) | Соответствие в нашем MVP |
|---|---|---|
| OCP (ocp.by) | Ответы на обращения: управление IVR, подключение по API к сервисам автоответов, логика распределения на операторов, запись разговоров, базовые отчёты, гибкая настройка CRM-карточки оператора с нужными полями | Телефония, IVR, маршрутизация, запись, карточка обращения |
| ChannelBox (help-desk.by) | Омниканальное взаимодействие с клиентами по текстовым каналам | Текстовые каналы, рабочее место оператора |
| HelpDesk (help-desk.by) | Создание и обработка обращений на 2-й линии: полный цикл — передача исполнителям, согласование, контроль ответов | Тикеты 2-й линии |
| (без названия) | LLM + RAG для обработки текстовых запросов, настройка цепочек ответов | Точки расширения ИИ (assist/bot) |

## 2. Указания заказчика («Промпт.docx») — ПРИОРИТЕТНЫЙ источник

- Разработать собственный программный продукт, автоматизирующий контакт-центр.
- Омниканальность: телефон + текстовые каналы (мессенджеры, чат на сайте, в приложении, email).
- Оператор работает в едином интерфейсе; автоматически выводятся подсказки и автоответы; **всё настраивается**.
- IVR, легко настраиваемая.
- «Фактически все требования указаны в документах. Можно сделать что-то подобное, но без каких-то сложных моментов.»
- Аналитика — проще; нужные отчёты доделаются по запросу позже. Сложное — можно отложить.
- **Главное — MVP, показывающий, что весь основной функционал работает.**
- Возможность подключать нейросети (автоответы, анализ) и сторонние продукты, чтобы клиенты сами получали информацию (балансы и т.д.).
- **Очень важно: обновления без остановки приёма и обработки обращений**, либо с минимальной задержкой и только когда обновление затрагивает блоки, которые не могут работать во время обновления.
- Работа с аудиогарнитурами — проводными и беспроводными.
- Передача на 2-ю линию поддержки, затем согласование закрытия тикета (с обработкой обращения) либо отправка на доработку.
- Сайзинг не нужен (требования к железу); лишнее и дубли убрать; работать через агентов, экономя контекст.
