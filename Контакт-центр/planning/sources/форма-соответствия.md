# Свод: «Форма соответствия ПО для контакт-центра»

**Файл:** лист «Требования к системе», 665 требований × 5 колонок: «№» (пусто), «Направление» (17 разделов сплошными блоками), «Требование», «Описание» (стр. 2–155 — детализация, далее — способ проверки на стенде), «Обязательно/желательно» (**пусто везде**).
Отметок соответствия продуктов и обязательности нет. [прим.] «Голосовые вызовы» (154 стр.) и «2ая линия» похожи на описание существующего продукта, прочее — на опросник поставщикам.

## TEL — Телефония
- FS-TEL-01 [MVP] WebRTC/SIP в браузере: вх./исх./внутр.; панель звонка на любой странице; hold, mute, DTMF, перевод слепой/с консультацией.
- FS-TEL-02 [MVP] Исходящий в 1 клик из карточки, ручной набор с нормализацией; понятные ошибки; стадии и длительности, постобработка.
- FS-TEL-03 [MVP] Переподключение с сохранением звонка; индикация софтфона и регистрации линии.
- FS-TEL-04 [MVP] Гарнитуры (Jabra, Plantronics): кнопки ответа/hold/mute.
- FS-TEL-05 [MVP] Журнал звонков (стадии, результат, перевод, связь с обращением); права телефонии на сервере; выключатель, демо-режим.
- FS-TEL-06 [MVP] Callback: личный/групповой, из IVR/API, лимит попыток. Автоответ, DND.
- FS-TEL-07 [MVP-упрощ.] Запись разговоров, плеер, правила записи; путь клиента IVR→очередь→оператор.
- FS-TEL-08 [Позже] Кампании обзвона (прогрессивный/предиктивный/робот, календарь); запись экрана; десктоп-софтфон [прим. вне «только браузер»].

## IVR
- FS-IVR-01 [MVP-упрощ.] IVR админом: меню, музыка, позиция в очереди, заказ перезвона. [прим.] Визуальный конструктор в форме не описан.
- FS-IVR-02 [MVP] Расписания линий, праздники, нерабочее время.

## OMNI — Каналы
- FS-OMNI-01 [MVP] Единое окно и единые правила/маршрутизация для всех каналов; файлы и голосовые; исходящие в разрешённых каналах.
- FS-OMNI-02 [MVP] Telegram-бот. [прим.] первый мессенджер — согласовать.
- FS-OMNI-03 [Позже] WhatsApp Business API, Viber, VK, MAX, Instagram, Facebook.
- FS-OMNI-04 [MVP] Email (IMAP/SMTP): неск. ящиков с очередями, треды, контроль подключения.
- FS-OMNI-05 [MVP] Каналы без остановки и без правки ядра (коннекторы); реестр, мастер с откатом, статусы, автопроверка, журнал обмена.
- FS-OMNI-06 [MVP] Канал→очередь по умолчанию; бот на канал; бот↔оператор с историей.
- FS-OMNI-07 [MVP-упрощ.] Внешний канал по API с ключом; формы сайта → обращения.

## WGT — Веб-чат / чат в приложении
- FS-WGT-01 [MVP] Виджет: неск. виджетов/очередей, белый список доменов, лимиты файлов, rate-limit.
- FS-WGT-02 [MVP] В мобильных приложениях (iOS/Android/Flutter: WebView/API) и ЛК; клиент по авторизованной сессии.
- FS-WGT-03 [MVP-упрощ.] Конструктор с предпросмотром; API виджета (сессия, история, оценки, согласия).

## OP — Рабочее место оператора
- FS-OP-01 [MVP] Браузер, рус. язык; три панели: обращения / чат / карточка клиента.
- FS-OP-02 [MVP] Список: вкладки (очередь, бот, мои, удержание, постобработка), ожидание, сортировка, фильтры, «Срочное».
- FS-OP-03 [MVP] Неск. диалогов; передача с контекстом; заметки; удержание; поиск.
- FS-OP-04 [MVP] Карточка клиента: кросс-канальная история, свои поля, звонки, оценки; хронология обращения.
- FS-OP-05 [MVP] Теги (обязательный при закрытии — опция); статусы (готов/перерыв с причиной/офлайн), таймер, автосмена при звонке.
- FS-OP-06 [MVP] Уведомления: звук, вкладка, push; личные настройки.
- FS-OP-07 [MVP-упрощ.] Панели/iframe CRM и БЗ; Close Guard; библиотека файлов.
- FS-OP-08 [Позже] Эмодзи, реакции, правка сообщений, голосовые оператора, тёмная тема, виджеты-дашборд, внутренний чат, PWA.

## RT — Распределение и очереди
- FS-RT-01 [MVP] Очереди (канал, приоритет, вес, по умолчанию); только свои очереди и статус «готов».
- FS-RT-02 [MVP] Мин. нагрузка, навыки (0–100), приоритеты; лимиты диалогов на оператора/очередь; учёт голоса при раздаче текста. SPQ/WFQ — [MVP-упрощ.].
- FS-RT-03 [MVP] Таймаут ответа, возврат в очередь, эскалация по ожиданию; ручное назначение супервизором с историей.
- FS-RT-04 [MVP] Удержание с автоснятием; постобработка 15–600 с, автозакрытие + опрос.
- FS-RT-05 [MVP-упрощ.] Правила: канал/фразы/regex → очередь/сотрудник/бот/«срочное»; приоритет, журнал.
- FS-RT-06 [MVP-упрощ.] Внешний маршрутизатор (таймаут, фолбэк); API назначения/статусов; события наружу.

## AUTO — Автоматизация
- FS-AUTO-01 [MVP] Шаблоны с поиском; автоответ; автозакрытие при молчании клиента.
- FS-AUTO-02 [MVP-упрощ.] Бот без кода: меню, форма до диалога, HTTP-вызов, перевод, версии.
- FS-AUTO-03 [Позже] Отложенные/повторные сообщения.

## AI — LLM/RAG
- FS-AI-01 [MVP] Точки расширения: облачные и локальные модели по функциям, шифр. ключи, проверка связи, фолбэк, отключение ИИ без сбоев.
- FS-AI-02 [MVP-упрощ.] Подсказки и черновик ответа оператору; RAG по БЗ (векторный поиск).
- FS-AI-03 [MVP-упрощ.] Шлюз внешних ботов: протокол, ключ, таймаут, команды, журнал.
- FS-AI-04 [Позже] Саммари, авто-тема для маршрутизации, тональность, перевод, свой ИИ-бот, учёт расходов.
- FS-AI-05 [Позже] MCP для ИИ-агентов: токены с правами, запрет ПДн, журнал.

## INT — Интеграции
- FS-INT-01 [MVP] REST API и webhooks: фильтр событий, неск. получателей, ретраи, журнал, тест, версии схемы; сбой не мешает оператору.
- FS-INT-02 [MVP-упрощ.] CRM: всплытие карточки, поиск клиента во внешней системе; журнал запросов; экспорт CSV/XLSX.
- FS-INT-03 [Позже] SSO/AD (роли по группам); iframe-сценарии, редиректы.

## REP — Аналитика (упрощённо)
- FS-REP-01 [MVP-упрощ.] Реалтайм-панель: очереди, операторы, пороги.
- FS-REP-02 [MVP-упрощ.] Отчёты: каналы, SL, AHT/ASA, 1-й ответ, нагрузка, статусы, CSAT; фильтры; CSV; единый часовой пояс, без тестовых данных, доступ по ролям.
- FS-REP-03 [Позже] Каталог, жизненный цикл, передачи, темы, бот, рассылка по расписанию, BI/API.

## QA — Качество
- FS-QA-01 [MVP] Оценка клиентом после диалога.
- FS-QA-02 [MVP-упрощ.] Супервизор: наблюдение, суфлирование, вмешательство.
- FS-QA-03 [Позже] Выборочная проверка, чек-листы.

## ADM — Администрирование
- FS-ADM-01 [MVP] Пользователи: CRUD, блокировка, «уволить», навыки, очереди, SIP.
- FS-ADM-02 [MVP] Роли (оператор, супервизор, админ, 2-я линия), дерево прав CRUD, права по очередям.
- FS-ADM-03 [MVP] Справочники (темы, теги, перерывы, навыки, часовые пояса); массовый импорт — [Позже].

## LOG — Журналы и мониторинг

- FS-LOG-02 [MVP] JSON-логи, централизованный сбор, healthcheck, метрики и оповещения.
- FS-LOG-03 [MVP-упрощ.] Журнал событий обращения для отчётов; маскирование секретов/ПДн.
- FS-LOG-04 [Позже] Сроки хранения, автоочистка, архивы, фоновые задания.

## PD — Персональные данные

- FS-PD-02 [MVP-упрощ.] Обезличивание клиента и уволенного сотрудника.
- FS-PD-03 [Позже] Автоистечение согласий, API согласий, обезличенная выгрузка.

- FS-ARCH-01 [MVP] Модули-сервисы; обновление компонента без остановки обработки.

- FS-ARCH-04 [MVP] БД: миграции, FK, индексы, бэкап PITR, доступ на уровне БД. [прим.] стр. 144–155 — схема чужого продукта, ориентир.

## TKT — 2-я линия
- FS-TKT-01 [MVP] Тикеты: список, создание, шаблоны, публ./внутр. комментарии, история, SLA-таймеры, массовые действия.
- FS-TKT-02 [MVP] [прим.] Согласование закрытия / возврат на доработку **в форме нет** — из ТЗ заказчика.
